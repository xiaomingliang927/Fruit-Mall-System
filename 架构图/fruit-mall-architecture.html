🍎🍊🍇水果商城系统架构图

用户端网站（PC/H5） + 微信小程序 + 管理后台 —— 三端一体，共用一套后端 API，数据实时同步
前后端分离RESTful API微信支付闭环
① 用户触点层 三个前端入口，同一套接口，仅登录方式与支付方式不同
🖥️用户端网站Vue3 + Nuxt(SSR)
  • 首页：轮播 / 分类导航 / 秒杀专区 / 热销榜
  • 商品：搜索筛选、多规格 SKU 详情、评价
  • 购物车：勾选结算、失效置灰、凑单提示
  • 下单支付：优惠券抵扣、微信 Native 扫码支付
  • 订单：物流跟踪、确认收货、售后退款
  • 会员中心：地址 / 收藏 / 足迹 / 优惠券
📱微信小程序uni-app
  • 微信一键登录（code → openid → 绑手机号）
  • 微信支付 JSAPI，支付回调驱动订单状态
  • 订阅消息：发货通知 / 退款结果 / 拼团结果
  • 分享裂变：商品海报、拼团邀请
  • 附近门店 / 自提导航（可选）
  • 客服消息即时沟通
🛠️管理后台Vue3 + Element Plus
  • 数据看板：销售额 / 订单量 / 热销 TOP10
  • 商品与库存：三级分类、SKU、上下架、预警
  • 订单管理：发货、面单打印、改址、批量操作
  • 售后审核：坏果包赔、退款打款
  • 营销管理：优惠券 / 秒杀 / 拼团 / 推荐位
  • 系统设置：RBAC 权限 / 运费模板 / 操作日志
▼统一 RESTful API · /api/v1（C 端）与 /api/admin（管理端）物理隔离 · 全站 HTTPS

🧾 核心业务流程 · 购买主链路

从浏览到售后的完整交易闭环
1浏览 / 搜索首页 · 分类 · 秒杀专区
→
2选规格 SKU重量 / 份 / 等级
→
3加购 / 立即买购物车勾选结算
→
4确认订单地址 · 配送 · 优惠券
→
5提交订单Redis 锁库存
→
6微信支付JSAPI / 扫码
→
7支付回调验签 + 幂等 → 待发货
→
8拣货发货快递 / 同城 / 自提
→
9物流配送轨迹实时可查
→
10确认收货手动 / 7 天自动
→
11评价晒单订单完成 · 可售后

🔄 订单状态机

状态流转与逆向分支
待支付下单锁库存
→支付成功
待发货扣实际库存
→商家发货
待收货配送中
→确认收货
7 天自动确认
已完成可评价
⏱ 超时分支：待支付 —超时 30 分钟 / 用户取消→ 已取消（自动释放库存）
🍊 售后分支（坏果包赔）：待发货 / 待收货 / 已完成(24h内) —申请→ 售后中 —审核通过→ 已退款（≤50 元自动秒退 · 原路退回微信）
