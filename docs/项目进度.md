### 2. 交易闭环（M1）

登录（短信 + 微信自动登录跨设备同账号）→ 商品（10 款果小满水果 + 真实摄影图）→ 购物车（**三端同步**）→ 下单（乐观锁防超卖）→ 支付（M1 模拟）→ 发货（运单号）→ 确认收货 → 评价。

### 3. M2 营销与服务（全部完成）

- **售后退款（坏果包赔）**：申请 → ≤50 元自动秒审 / 超额人工审核 → 退款回库存 / 驳回恢复订单状态；用户可撤销
- **优惠券**：后台建券（满减/折扣/无门槛，限领/总量/时间窗）→ 领券中心（网站+小程序）→ 结算页选券抵扣 → 取消退券；乐观扣减防超发
- **评价系统**：完成单评价（星级/内容/匿名，明细粒度防重复）→ 商品详情评分聚合（均分+条数）→ 后台回复 / 显示隐藏
- **图片上传闭环**：后端上传接口（jpg/png/webp ≤5MB，日期分目录）+ 磁盘静态映射 `/uploads/**`；网站售后弹层选图即传（≤3 张、可删可重选）、小程序 `chooseImage` + `uploadFile`（相册/拍照/压缩）、管理后台售后审核页凭证缩略图 + 大图预览

### 4. 三端界面

- **网站**（Vue3+Vite，:5173）：首页（Hero/热销榜/保障条）、详情+评价区、购物车、结算选券、订单（支付/取消/确认/售后<含凭证传图>/评价）、领券中心、我的账户/收藏
- **管理后台**（Element Plus+ECharts，:5174）：六大中心分组菜单、经营看板（趋势/占比/状态环图）、营业统计+Excel 导出、商品/订单/售后（凭证图预览）/评价/优惠券管理、会员卡（开卡续费/临期筛选）
- **小程序**（uni-app 果小满 UI，CLI `miniapp/` + HBuilderX `miniapp-hbx/`）：真实后端数据、跨端购物车同步、TabBar 数量角标、领券/评价/售后全流程（售后可拍照传凭证）、真实 AppID 已配置

### 5. 数据库

20+ 张表（用户/商品/交易/营销/售后/评价/内容/RBAC/日志），完整设计文档见 [数据库设计.md](数据库设计.md)；金额一律分制存储；订单明细快照化。
